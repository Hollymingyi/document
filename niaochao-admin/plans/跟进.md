# 客户跟进配置 — 实现计划

## 参考文档
- PRD：`D:/prototype/鸟巢侧改造.md` §3.1（关联坐席组）、§3.2（跟进节点）、§3.3（跟进表单）
- 原型页面：`D:/prototype/prototype-客户跟进配置.html`

## 功能目标
在客户档案详情页新增 3 个 Tab：「关联坐席组」「跟进节点」「跟进表单」，实现客户级独立配置。样式和交互严格对齐原型。

## 注意事项
1. 样式包括文字、颜色等都要与原型保持一致，避免返工
2. 功能要参照 PRD §3.1 §3.2 §3.3，不能自行臆造
3. 做完每个功能按键、子页面的功能都要自测（用 playwright-cli）

## 二、Tab 1：关联坐席组（PRD §3.1）

### 2.1 顶部统计行
- 关联状态：已关联（绿点+绿字）/ 未关联
- 绑定坐席组：`N 个`（蓝色高亮）
- 右侧：`前往坐席组管理` 按钮
- 副标题提示：`该客户共绑定 {N} 个坐席组（N:1 关系）。客户视角为只读；新增/启停/重置密码请前往坐席组管理。`

### 2.2 坐席组卡片列表（折叠卡形态）

每张卡分**卡头**和**卡体**：

**卡头**（始终可见，4 列 grid 布局）：
| 列 | 内容 |
|----|------|
| 第1列 | 第一行：坐席组名称（蓝色可点击→跳转坐席组详情）+ 状态标签；第二行（小字灰）：坐席组ID + 备注 |
| 第2列 | 组长：头像+姓名+`+N` popover |
| 第3列 | 坐席人数：`X 启用 / Y 禁用` |
| 第4列 | 展开按钮 `查看坐席列表 ▾` |

**卡体**（默认折叠，点击展开）：
- 内部筛选：账号/姓名/分机号 + 角色 + 状态
- 坐席表格列：账号（蓝色）、真实姓名、角色（多chip：组长/坐席）、分机号（等宽）、状态、最后登录、创建时间
- **只读**，无任何操作按钮
- 分页

**折叠规则**：
- 仅 1 个坐席组 → 默认展开
- 多个坐席组 → 默认全部折叠
- 已禁用坐席组 → 卡片背景灰化 + 橙色提示 `⚠ 已禁用，不可被新任务使用`

### 2.3 未关联场景
- 空状态：大号图标 + `未关联坐席组` + `该客户尚未绑定任何坐席组，人机协作任务将无法创建` + `前往配置` 按钮

### 2.4 数据来源
- 通过 customerCode 查询关联坐席组：复用 `queryAgentGroupsApi` + 按 customerCode 过滤
- 每个坐席组的成员列表：复用 `/agent-group/members` 接口（已有）

## 三、Tab 2：跟进节点配置（PRD §3.2）

### 3.1 节点集列表

**表头**：
| 列 | 说明 |
|----|------|
| 节点集名称 | 蓝色可点击→编辑抽屉 |
| 节点数量 | 该集合下节点条数 |
| 已关联任务数 | 引用该节点集的任务总数（蓝 tag） |
| 节点预览 | 前 3 个节点 chip（①②③）+ `+N` |
| 状态 | 启用 / 禁用 |
| 创建时间 | 排序字段 |
| 操作 | 编辑、复制、禁用/启用、删除（已关联时禁用） |

**筛选**：节点集名称模糊 + 状态
**空态**：`暂无节点集` + `+ 新建节点集`

### 3.2 新建/编辑节点集抽屉（640px 宽）

**基本信息区**：
- 节点集名称（必填，客户内唯一）
- 启用状态（switch 开关）
- 备注（选填）

**节点列表区**（核心交互）：
- 每行节点：`⋮⋮` 拖动手柄 + 序号圆（①②③）+ 输入框 + 删除按钮
- 底部：`+ 添加节点` 虚线按钮
- 拖拽排序（使用 vuedraggable 或 sortablejs）
- 集内唯一校验（保存时）
- 剩余 1 项时不可删除

**编辑限制（已关联任务）**：
- 黄色 alert 提示：「该节点集已被 N 个任务关联使用，仅允许新增节点/调整顺序，不允许删除或重命名已有节点」
- 已使用节点行：白底 + 虚线边框 + `已使用` 灰色标签，输入框 disabled，无删除按钮
- 新增节点行保持正常可编辑

**通用约定**（§3.2/§3.3 共享）：
- 禁用确认：`禁用后，新建任务下拉项不再展示该项；已引用任务不受影响。`
- 删除确认：`删除后不可恢复。仅"无关联任务"允许删除。`
- 复制：默认名称 `{原名}-副本`，复制后默认状态 = 禁用

## 四、Tab 3：跟进表单配置（PRD §3.3）

### 4.1 跟进表单列表

**表头**：
| 列 | 说明 |
|----|------|
| 表单名称 | 蓝色可点击→编辑抽屉 |
| 字段数量 | 该表单字段总数 |
| 已关联任务数 | 引用该表单的任务总数 |
| 字段类型预览 | 前 3 种字段类型 chip（如：单行/单选/日期）+ `+N` |
| 状态 | 启用 / 禁用 |
| 创建时间 | 排序字段 |
| 操作 | 编辑、复制、禁用/启用、删除（已关联时禁用） |

**筛选**：表单名称模糊 + 状态
**空态**：`暂无跟进表单` + `+ 新建表单`

### 4.2 新建/编辑表单抽屉（880px 宽）

**表单基本信息**：
- 表单名称（必填，客户内唯一）
- 启用状态（switch 开关）
- 备注（选填）

**字段构造器**（核心交互，7 种字段类型）：

| 字段类型 | 图标色 | 专属配置项 |
|---------|--------|-----------|
| 单行文本 | 蓝色 | 占位提示、最小字符数、最大字符数 |
| 多行文本 | 蓝色 | 最小字符数、最大字符数、行数（默认3） |
| 单选 | 蓝色 | 选项列表（≥2项）、默认选中、展示样式（横向/纵向） |
| 多选 | 蓝色 | 选项列表（≥2项）、默认选中（多选）、展示样式、最少/最多选项数 |
| 下拉 | 蓝色 | 选项列表（≥2项）、默认选中、是否允许搜索 |
| 日期 | 蓝色 | 日期类型（仅日期/日期+时间）、可选范围（不限/仅未来/仅过去） |
| 数字 | 蓝色 | 最小值、最大值、小数位数 |

**字段行交互**：
- 每个字段 = 卡片，可折叠/展开
- 卡头：`⋮⋮` 拖动手柄 + 类型图标 + 字段名输入框 + 类型下拉 + 必填勾选 + 复制/折叠/删除按钮
- 卡体（展开后）：各类型专属配置项
- 拖拽排序
- 底部：`+ 添加字段` 网格选择器（4列×2行，展示7种类型卡片）

**编辑限制（已关联任务）**：
- 灰底 + `已使用` 标签，字段名 disabled，删除按钮→锁定图标
- 仅允许新增字段

**预览表单**：
- 抽屉底部 `预览表单` 按钮
- 弹出模态框，以最终用户视角渲染当前字段配置

## 五、后端 API 需求

### 5.1 跟进节点集 API（新增，gt-system）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/follow-node-set/list` | 查询客户的节点集列表（customerId） |
| POST | `/follow-node-set/create` | 新建节点集 |
| POST | `/follow-node-set/update` | 编辑节点集 |
| POST | `/follow-node-set/changeStatus` | 启用/禁用 |
| POST | `/follow-node-set/copy` | 复制节点集 |
| DELETE | `/follow-node-set/delete/{id}` | 删除（仅无关联任务时） |

### 5.2 跟进表单 API（新增，gt-system）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/follow-form/list` | 查询客户的表单列表（customerId） |
| POST | `/follow-form/create` | 新建表单 |
| POST | `/follow-form/update` | 编辑表单 |
| POST | `/follow-form/changeStatus` | 启用/禁用 |
| POST | `/follow-form/copy` | 复制表单 |
| DELETE | `/follow-form/delete/{id}` | 删除（仅无关联任务时） |

### 5.3 数据库新增表

```sql
-- 跟进节点集
CREATE TABLE follow_node_sets (
  id            BIGINT AUTO_INCREMENT PRIMARY KEY,
  customer_code VARCHAR(30) NOT NULL COMMENT '客户编码',
  name          VARCHAR(50) NOT NULL COMMENT '节点集名称，客户内唯一',
  nodes         JSON NOT NULL COMMENT '节点列表，有序数组 ["已加微","已邀约",...]',
  status        TINYINT NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
  remark        VARCHAR(200) DEFAULT NULL,
  task_count    INT NOT NULL DEFAULT 0 COMMENT '已关联任务数（冗余计数）',
  create_by     VARCHAR(50) DEFAULT NULL,
  create_time   DATETIME DEFAULT NULL,
  update_by     VARCHAR(50) DEFAULT NULL,
  update_time   DATETIME DEFAULT NULL,
  UNIQUE KEY uk_customer_name (customer_code, name),
  KEY idx_customer_code (customer_code)
) COMMENT '跟进节点集';

-- 跟进表单
CREATE TABLE follow_forms (
  id            BIGINT AUTO_INCREMENT PRIMARY KEY,
  customer_code VARCHAR(30) NOT NULL COMMENT '客户编码',
  name          VARCHAR(50) NOT NULL COMMENT '表单名称，客户内唯一',
  fields        JSON NOT NULL COMMENT '字段配置列表',
  status        TINYINT NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
  remark        VARCHAR(200) DEFAULT NULL,
  task_count    INT NOT NULL DEFAULT 0 COMMENT '已关联任务数（冗余计数）',
  create_by     VARCHAR(50) DEFAULT NULL,
  create_time   DATETIME DEFAULT NULL,
  update_by     VARCHAR(50) DEFAULT NULL,
  update_time   DATETIME DEFAULT NULL,
  UNIQUE KEY uk_customer_name (customer_code, name),
  KEY idx_customer_code (customer_code)
) COMMENT '跟进表单';
```

`fields` JSON 示例：

  {

    "type": "single_select",

    "required": false,
    "options": ["电话", "微信", "面访"],
    "defaultValue": null,
    "layout": "horizontal",
    "locked": false
  }
]

## 七、实施顺序

1. **Phase 1 — 客户详情页骨架**：路由、detail.vue 页头+Tab 容器、基础档案 Tab
2. **Phase 2 — 关联坐席组 Tab**：统计行 + 折叠卡片列表 + 未关联空态（纯前端，复用已有 API）
3. **Phase 3 — 跟进节点 Tab**：后端 API + 前端列表 + 新建/编辑抽屉（含拖拽排序）+ 编辑限制逻辑
4. **Phase 4 — 跟进表单 Tab**：后端 API + 前端列表 + 字段构造器 + 预览模态框 + 编辑限制逻辑
5. **Phase 5 — 客户列表页改造**：新增 3 列 + 客户名称跳转

## 八、依赖项

- `vuedraggable` 或 `sortablejs`：节点列表和字段列表的拖拽排序
- 后端新增 API 和数据表（Phase 3/4 依赖后端先完成）
